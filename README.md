# yplus-website
New design for yplus.ps, deployed via GitHub Actions to the TwoIDs subfolder.

## One Love, Two IDs
Interactive story — first experience of the Y+ Communicating Palestine toolkit.

- `index.html` — the interactive
- `toolkit-data.json` — all copy in EN / IT / FR / AR, sources, badge keys
- `support.js` — runtime
- `assets/yplus-logo.png`
- `ANALYTICS.md` — GA4 events and setup (Measurement ID G-NMEYZ7ZWB5 is built in)

Language via `?lang=ar|en|it|fr`. Kiosk mode: edit `"mode"` default in `index.html` data-props.
